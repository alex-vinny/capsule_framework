# Contributing to Capsule Framework

Thank you for considering a contribution! The full guide lives at the repository root so GitHub
shows it next to every pull request:

- **[CONTRIBUTING.md](https://github.com/alex-vinny/capsule_framework/blob/main/CONTRIBUTING.md)** — setup,
  the test layers (TypeScript, Kotlin, Android instrumented, Swift in Docker, docs), and what a
  pull request needs.
- **[Code of Conduct](https://github.com/alex-vinny/capsule_framework/blob/main/CODE_OF_CONDUCT.md)** —
  Contributor Covenant 2.1.
- **[Security policy](https://github.com/alex-vinny/capsule_framework/blob/main/SECURITY.md)** — report
  vulnerabilities privately, never in a public issue.

## Reporting bugs

Use the issue tracker. Provide a clear title, steps to reproduce, expected vs. actual behavior,
the platform (Android / iOS / browser dev mode) and versions, and any relevant logs.

## Suggesting features

Open an issue with the `enhancement` label: the problem it solves, how it would work, and any
drawbacks. Check the [roadmap](../project/roadmap.md) first — it may already be planned.
